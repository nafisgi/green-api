# WhatsApp Чат через GREEN-API

Небольшое приложение для текстовой переписки в WhatsApp. Клиент написан на React 19 и TypeScript и обращается к GREEN-API напрямую из браузера. Интерфейс содержит подключение инстанса, создание чата по номеру телефона, отправку текста и получение ответов.

## Запуск

Используйте Node.js 22 (`.nvmrc`):

```bash
npm ci
npm run dev
```

Откройте `http://localhost:5173`. Для проверки собранной версии выполните `npm run build` и `npm run preview`. Папку `dist` можно разместить на статическом хостинге.

## Переменные окружения

| Переменная       | Назначение                                 | Значение по умолчанию |
| ---------------- | ------------------------------------------ | --------------------- |
| `VITE_BASE_PATH` | Базовый путь сайта для Vite и React Router | `/`                   |

Для GitHub Pages в репозитории `username.github.io/repo/` соберите проект командой `VITE_BASE_PATH=/repo/ npm run build` и опубликуйте `dist`.

## Подключение

1. Создайте и авторизуйте инстанс **GREEN-API WhatsApp**.
2. Включите `incomingWebhook` и оставьте `webhookUrl` пустым для получения через HTTP API.
3. Введите `apiUrl` из кабинета GREEN-API, `idInstance` и `apiTokenInstance`.
4. Нажмите «Новый чат», введите номер с кодом страны (11–16 цифр) и напишите текстовое сообщение.

Приложение проверяет инстанс методом `GetSettings`, ищет адресата через `CheckWhatsapp`, отправляет текст через `SendMessage` и читает ответы через `ReceiveNotification` с последующим `DeleteNotification`. Для отправки используется `chatId`, возвращённый `CheckWhatsapp` (`@lid` или `@c.us`).

Токен и переписка находятся только в памяти вкладки. Токен включается в URL запросов к GREEN-API и виден пользователю в сетевых инструментах браузера; не передавайте его другим людям. После перезагрузки нужно подключиться заново; история прошлых сеансов не загружается. Очередь уведомлений следует читать из одной вкладки для одного инстанса.

Прямые запросы зависят от CORS-настроек API-хоста инстанса. Если браузер блокирует запросы, используйте адрес из кабинета GREEN-API; при отсутствии разрешения CORS на этом хосте потребуется отдельный шлюз.

## Структура

| Слой             | Содержимое                                                  |
| ---------------- | ----------------------------------------------------------- |
| `src/app`        | Провайдеры, маршрутизатор, границы ошибок, глобальные стили |
| `src/pages/chat` | Композиция единственного экрана                             |
| `src/features`   | Подключение, создание чата, отправка и получение            |
| `src/entities`   | Модели чата, Zustand-состояние, API и отображение           |
| `src/shared`     | HTTP-клиент Ky, конфигурация, утилиты и UI-примитивы        |

Импорты направлены от верхних слоёв к нижним. Features не импортируют друг друга. В `shared/ui` нет общего barrel-файла. UI-примитивы используют Tailwind CSS и Radix, формы — React Hook Form с Zod, запросы — TanStack Query. Сессия и локальные сообщения находятся в слайсах Zustand без `persist`.

## Проверки

```bash
npm run lint
npm run typecheck
npm test
npm run test:coverage
npm run build
```

Vitest с MSW проверяет клиентский сценарий отправки и получения и формат прямых HTTP-запросов. Для проверки реального обмена нужны действующие данные инстанса и второй аккаунт WhatsApp. CI выполняет установку, линтер, проверку типов, тесты и сборку.

Документация: [SendMessage](https://green-api.com/docs/api/sending/SendMessage/), [HTTP API](https://green-api.com/docs/api/receiving/technology-http-api/), [CheckWhatsapp](https://green-api.com/docs/api/service/CheckWhatsapp/).
